# Steam macOS ARM64 client 1791918634

Reviewed on 2026-10-14.

- ARM64 Mach-O UUID: `335cba8adcef3512948915b22ff702d6`.
- ARM64 slice SHA-256: `4572d4e2cc734c719b2d4a9333e1c572b464b2e31970748d9c81b33017bc4106`.
- Executable `__text` SHA-256: `7b9edeb2b7dc06c4fd11006ecbc438ce96d8386630ec8270c5ee0dfd22fc3299`.

Evidence comes from Apple's `otool -arch arm64 -tvV` on the installed Valve
library and Mach-O section/UUID parsing as ordinary static observations.

The compatibility manager constructor compares the platform name with `linux`
at `0x6a1950–0x6a1964`, storing the result at self + `0x810` at `0x6a1968`.
The disable function logs `Disabling compatibility layer.` and clears that field
at `0x6a3c40`. This confirms the field's meaning independently of its offset in
the preceding client, where it was at `0x7b0`.

The twelve reads in the TOML belong to the adjacent compatibility-manager
methods. Named profiler strings identify app configuration, licensing,
post-logon processing, experiment selection, eligibility and platform overrides.
The trivial getter at `0x6a3c14` returns this field directly. Reads of `0x810`
outside this compatibility-manager region are excluded.

Eligibility entry `0x6a5adc` stores x0 as self and w1 as the AppID; its profiler
reference at `0x6a5b0c` names `CCompatManager::BIsCompatibilityToolEnabled`.
Its boolean result returns in x0 at `0x6a5bfc–0x6a5c0c`. Both platform-state
reads inside this function are included in the contract.

The OS-list method at `0x6a5628` checks the selected tool pointer separately at
`0x6a56d8`. `V_stristr` at `0x6a56f4` checks the requested OS list against the
tool's list; its result is tested by CBZ x0 at `0x6a56f8`, which returns false
through `0x6a568c`. Only this OS-list gate is replaced with NOP. Null-tool and
other status checks remain intact.

The implementation validates UUID, the full executable-text hash, all eight
eligibility-entry words and every patch instruction before installing anything.
Static review does not establish game rendering or general client compatibility.
